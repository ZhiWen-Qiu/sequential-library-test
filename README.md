# Sequential Gallery

在瀏覽器裡調整照片：從 25 張不同效果的小圖中挑出最喜歡的，系統會依照你的選擇越挑越準。也可以用滑桿手動調整，或裁切、旋轉照片，最後下載 JPG。

- 照片只在瀏覽器裡處理，不會上傳到任何地方。
- 支援 JPG、PNG、WebP。

方法出自 Yuki Koyama, Issei Sato, Masataka Goto. "Sequential Gallery for Interactive Visual Design Optimization." ACM Transactions on Graphics 39(4), 2020.

## 檔案

- `index.html`：網頁本體（介面、照片處理）
- `bo.js`：Sequential Plane Search 演算法（貝氏最佳化）
